## Featured work

### [PaperIntel](https://github.com/Harippriyasiva/PaperIntel) · [Try the live app](https://paperintel-haripriya.streamlit.app/)

A research-paper reader that connects questions to source evidence. It discovers papers on arXiv, prepares PDF text for search, retrieves relevant passages, and shows page-linked citations so readers can inspect the source. Built with Python, Streamlit, and retrieval-augmented generation. Answer generation depends on a configured model service; the live app also lets you inspect retrieved evidence directly.

### [NOSE research workflow](https://github.com/RamanLab/NOSE) · [PyPI package](https://pypi.org/project/nose-pipeline/)

A modular Python and Snakemake workflow for reproducible scientific analysis. My work at IIT Madras included connecting tools across six stages, adding validation, and supporting Docker, Conda, and Linux execution for research workflows.

### [Smart Skin Care](https://github.com/Harippriyasiva/SkinCancerDetection)

A CNN-based image-classification project covering preprocessing, training, evaluation, and an interface for exploring predictions. [Read the paper](https://ijsrem.com/download/smart-skin-care-deep-learning-in-skin-cancer-detection).
